How this works and how to use the key
  • Each pair is a random 32-byte ed25519 seed from crypto.getRandomValues. The public key is derived here, in plain JavaScript inside this file.
  • Private key = base58 of the 32-byte seed (the privkey field of the official client's wallet.json). Address = poa1 + base58 of the 32-byte public key.
  • This is a self-custody key for the official poa.mjs client: save Download wallet.json into a folder and pass it with --wallet. It is not a hosted pk_… API key; a new address exists on the ledger only after it joins.
  • The page's Content-Security-Policy forbids every network connection, image, font and frame load. For maximum safety, save this file and open it with your network turned off.
  • Check live balance opens a separate page, check.html, which needs an internet connection. It is read-only, never sees your private key, and its own Content-Security-Policy allows requests to https://minepoa.com only. This page's policy is unchanged: it still blocks every connection.
